# quantum-robot

The home of the quantum-robot open-source ecosystem.

The quantum-robot organization hosts the project website and will gradually
provide additional tools, extensions, and related projects for quantum-like
perception modeling in robotics.

## Main project

The core quantum-robot package is currently developed and maintained in the
[Davidelanz/quantum-robot repository](https://github.com/Davidelanz/quantum-robot).

Learn more:

- [Project website](https://quantum-robot.github.io/)
- [Documentation](https://docs.quantum-robot.org/en/latest/)
- [Main repository](https://github.com/Davidelanz/quantum-robot)
- [quantum-robot on PyPI](https://pypi.org/project/quantum-robot/)

More projects and add-ons will be published here over time.
